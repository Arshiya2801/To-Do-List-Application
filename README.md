# To-Do List Application

A simple and responsive To-Do List application built with **ReactJS** to help you manage and crush your daily goals! 💪

---

## Features

1. Add new tasks
2. Edit tasks inline
3. Mark as complete/incomplete
4. Delete tasks
5. Clear completed tasks
6. Filter out different tasks under the tags active, completed
7. Persistent using localStorage
8. Clean, mobile-responsive UI with TailwindCSS
9. Built with modern tooling (React + Vite)
